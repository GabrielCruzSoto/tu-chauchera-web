# Component Scaffolder

Genera el componente solicitado asegurando las siguientes especificaciones:

## Especificaciones
1. **Estados de interacción completos:** Implementa explícitamente `default`, `hover`, `active`, `focus-visible`, `disabled`, `loading` y `empty` (si aplica).
2. **Responsividad:** Asegura adaptabilidad fluida para viewports móviles, tablets y escritorio.
3. **Retroalimentación visual:** Incorpora transiciones breves y funcionales (150ms a 250ms con curvas estándar `ease-in-out`).
4. **Claridad en props/parámetros:** Declara interfaces claras para variantes visuales (solid, outline, ghost), tamaños (sm, md, lg) y slots para iconos o contenido dinámico.
