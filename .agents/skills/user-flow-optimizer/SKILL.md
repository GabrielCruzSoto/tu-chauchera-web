# User Flow Optimizer

Evalúa el flujo o formulario provisto bajo principios de UX cognitiva:

## Procedimiento
1. **Cuenta de pasos e inputs:** Identifica campos innecesarios o que puedan inferirse automáticamente.
2. **Validación y feedback:** Propón validación en línea (*inline validation*) y mensajes de error preventivos y concisos (UX Writing claro).
3. **Carga cognitiva:** Aplica la Ley de Hick para reducir el número de decisiones por pantalla y propone patrones de guardado o avance progresivo.
4. **Entregable:** Entrega un diagrama paso a paso de 'Estado Actual vs. Estado Propuesto' con los puntos de fricción eliminados.
